# Todo

A minimal todo app: plain HTML, CSS and JavaScript — no build step, no dependencies.

## Run it

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Features

- Add a todo with the input field or `Enter`
- Toggle completion with the checkbox
- Delete a todo with the `×` button
- Filter by All / Active / Completed
- Clear completed items
- Todos persist in `localStorage` across reloads
